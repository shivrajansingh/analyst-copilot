# Evaluation runner

`scripts/eval/run_practice.py` answers questions from `data/questions-by-doc.json` and writes `data/eval-results.json`.

## Input

`data/questions-by-doc.json` is an array of:

```json
{
  "doc_path": "filings/3M_2018_10K.htm",
  "questions": ["...", "..."]
}
```

Rebuild it from the JSONL:

```bash
PYTHONPATH=src python scripts/examples/build_questions_by_doc.py
```

## Run

```bash
# First N questions (flattened across docs)
PYTHONPATH=src python scripts/eval/run_practice.py --limit 5

# All 136
PYTHONPATH=src python scripts/eval/run_practice.py

# Resume-style slice
PYTHONPATH=src python scripts/eval/run_practice.py --offset 10 --limit 20
```

Results are written after **each** question so a long run can be interrupted without losing earlier rows.

## Output shape

```json
[
  {
    "doc": "filings/3M_2018_10K.htm",
    "question": "...",
    "answer": {
      "text": "actual answer generated by model",
      "evidence": "evidence from the doc reference",
      "found": true,
      "page": 60
    }
  }
]
```

This file is model output, not the gold key. Scoring against `practice-questions.jsonl` is a later step.
